# ENABLE word list

This project uses ENABLE (Enhanced North American Benchmark Lexicon) as its default open word-game dictionary. ENABLE was released into the public domain by its maintainers and is widely used as an alternative to proprietary tournament lexicons.

Mirror used by the setup script: https://raw.githubusercontent.com/dolph/dictionary/master/enable1.txt

The generated game dictionary keeps alphabetic words from 3 through 16 letters and then applies this project's allow/block overrides.
